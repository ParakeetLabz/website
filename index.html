About

Parakeet Labz is a small indie studio building fast, fun tools for the web. We make Parakeet, a browser-based web proxy, and Z Games, a free browser games hub. Everything we ship is open source — come build with us.

Open source — our code lives on GitHub under the ParakeetLabz organization.
No accounts, no tracking — our tools work the moment you open them.
Built for speed — every project is tuned to load fast and stay fast.
